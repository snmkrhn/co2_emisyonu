# co2_emisyonu
📌 Proje Hakkında
CO₂ emisyonu verileri kullanılarak farklı modeller eğitilmiştir.
Kuantum makine öğrenmesi teknikleri, klasik yöntemlerle kıyaslanmıştır.
Model performansları doğruluk, hata oranı ve işlem süresi gibi metriklerle karşılaştırılmıştır.
🛠 Kullanılan Teknolojiler
Python
Qiskit (IBM Quantum Computing)
TensorFlow / Scikit-learn
Pandas & NumPy
Matplotlib & Seaborn
🔬 Model Karşılaştırması
✅ Klasik Modeller: Doğrusal Regresyon, Random Forest, XGBoost
✅ Kuantum Modeller: Kuantum Destek Vektör Makineleri (QSVM), Kuantum Sinir Ağları (QNN)
✅ Metrikler: Doğruluk (Accuracy), Ortalama Kare Hata (MSE), Çalışma Süresi
